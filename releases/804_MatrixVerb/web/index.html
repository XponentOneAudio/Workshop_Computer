Card presets

Eight presets kept in the card's own flash, which the card loads with the 8mu alone (hold A and move a fader), and saves (hold D and move a fader). At power-up the card loads the last one saved or loaded. Save puts the settings here into the slot.

Browser presets

    Presets in this browser, as many as you like. Click a name to load it (and send it to the card). → slot copies one into a card preset without loading it. Back up card copies the card's presets here; Export saves them all to a file.

    How it works

    Eight delay lines run in a loop. Every sample, each line's output goes through its decay gain and damping filter, then the matrix mixes the eight back into the eight lines, with a share of the input. Each line's output share is heard, at its pan.

    Normalising. A matrix can amplify, and in a loop that runs away. So before it's used, the matrix is scaled by its spectral norm (its largest singular value, shown as σ), so it can never gain energy. With Normalise up, it's scaled to exactly σ = 1, so it loses nothing and the decay is all down to the Decay fader; down, a matrix is only ever scaled down, so a weak one (say, mostly zeros) dies away on its own. A matrix with every singular value 1 is orthogonal: it mixes without losing anything, which is what a smooth reverb wants. Uneven singular values make some patterns die faster than others.

    Blend fades between the identity (each line feeds only itself: eight separate combs, metallic) and the matrix. The eigenvalues show the matrix's own patterns: on the unit circle, lossless; inside it, dying.

    Coprime lengths. If two lines' lengths share a factor, their echoes pile up on the same moments and ring. So every length is snapped to the nearest that shares no factor with the lines before it (line 1 first): the factors are shown under each line.

    Safety. On top of the normalising: every line is written through a soft saturation, so nothing can grow past full scale; a guard pulls the feedback down if the network sits near full scale for a quarter of a second; the wet signal has its DC removed and passes a peak limiter set by Ceiling; power-up, Clear and loading a preset start from silence and fade in; and the output is soft clipped.

    How it connects

    The card picks its USB mode at power-up. 8mu plugged into the card: the card reads it directly and this page isn't used. Computer plugged into the card: the card appears as a MIDI device called MatrixVerb, and an 8mu plugged into this computer is passed on by this page. After plugging a computer in, power-cycle the module.
    Help
    • Use Chrome, Edge or another Chromium browser. Safari and iOS browsers can't do WebMIDI with SysEx.
    • Press Connect card & 8mu and allow MIDI with SysEx when the browser asks.
    • On-screen faders: drag, or focus one and use the arrow keys. Double-click resets one to its default.
    • Matrix: click a row to show it on the faders; drag a cell up or down to change it; double-click a cell to zero it.
    • Keys: 1-8 matrix rows, B C D as the 8mu's buttons, F freeze, X clear, Space click, Ctrl/⌘+Z undo a matrix tool.
    • The impulse response is simulated in this page, from the settings (with the card's knobs when it's connected). It leaves out the modulation, drive and the limiter, so the card sounds a little different, but the shape is the same.
    • Without a card the page still edits, simulates and keeps presets.
