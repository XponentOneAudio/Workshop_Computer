# Models

`nam_core_test_wavenet.nam` is the small test model (`example_models/wavenet.nam`) from [NeuralAmpModelerCore](https://github.com/sdatkinson/NeuralAmpModelerCore), copyright (c) 2023 Steven Atkinson, MIT licence. According to its metadata it is a capture of a Darkglass Electronics Microtubes 900 v2 by Steve. It is a very small WaveNet (3 and 2 channels, 3 layers), so it fits on the Computer easily, but it is only an approximate capture of the original.

It is the model built into `nam_amp.uf2`. Replace it with your own using `tools/nam2header.py` (see the main README).
